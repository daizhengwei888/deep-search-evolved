**口径清洗规则：**

1. 原始记录给出 22 次判定（21 胜、1 平、0 负），其中**一次交叉评测旧版未能产生有效输出**，却记为新版获胜；对双版本质量的成对比较而言，这一项无效。
2. 排除该记录后，真正可进行新旧版本对照的是 **21 次：新版 20 胜、1 平、0 负**。原始记录中的「22 次」「21 胜」只能作为*原始判定数*，不能作为有效对比数据。
3. 原始交叉评测记录报告旧版均分 6.80、新版均分 8.83；由于未提供逐次评分与缺失样本的可复核计算口径，**未重新计算剔除无效记录后的均分，因此在清洗表格中留空**。切勿把该组原始均分解释成这 8 组有效配对的平均成绩。
4. 其余两组均分直接采用原报告，属于 10 分制判官相对评分；差值是“分”，不是百分比，也不代表客观准确率。
5. 联网实验是同一个研究问题由三位评审分别判定，**3 次判定不等于 3 个独立研究问题**。

## 实验方法

- **对照版本**：Deep Search 4.0.0（旧）与 Deep Search 5.0.1（新）。
- **环境**：本机 macOS；同一实验条件下，按照两版 Skill 规则生成回答，使用相同网关模型配置。
- **盲评原则**：评审不看版本标签；三模型交叉实验还避免“模型评价自己生成的答案”。
- **离线组的五个考察维度**：研究规划、简短事实、指标口径冲突、引用是否支持断言、工具不可用时的可信回答。
- **交叉组的三个维度**：窄事实直答、口径冲突、引用核验。原报告有一条缺失有效旧版输出。
- **联网组的题目**：“中国未来家政服务趋势”。两版使用相同检索材料（四个读过的页面），三位判官分别盲评。新版本会识别转载与同源材料，标记未核实的行业报告数据，而不是直接纳入核心结论。

## 局限与复现

- 题量小，涵盖的研究能力有限，不足以证明在所有深度研究任务上均优于旧版。
- 盲评仍然是模型主观评分；不同判官之间可能存在共同偏差，且部分模型经同一网关调用，并非跨平台完全独立验证。
- 新旧规则比较不是不同基础大模型之间的性能比较；没有证明真实事实准确率提高了某个百分比。
- 目前仅有汇总记录，**未附逐题输入、原始输出、逐次评分及运行日志**；因此读者尚无法独立复算每个评分。需要补齐原始评测 artifacts 才能严格复现。

项目内可用 `SKILL.md` 了解规则，用 `evals/` 了解评估入口；正式对照应使用**未出现在训练或内置评测题库中的新题**，分别保存两版输出、盲评结果、超时记录与模型配置。
